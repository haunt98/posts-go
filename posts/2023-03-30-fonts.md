# Fonts

I always want the best fonts for my terminal, my text editor, my ... But I'm not satisfied easily, so I keep trying new
fonts. Prefer free fonts of course :D

TLDR:

On macOS, prefer [San Francisco](https://developer.apple.com/fonts/). Remember each time macOS release new version/new
update, you should download again to get (maybe) latest version.

Otherwise:

- Use [Inter](https://github.com/rsms/inter) for display.

Prefer:

- If macOS choose **OTF**, otherwise choose **TTF** format.
- If macOS ignore hinting, otherwise use hinting.
- Choose static font over variable font.

My standard for choosing fonts:

- Support Vietnamese
- Support bold, italic
- Has dotted zero, because I dislike slashed zero

Manually install fonts:

- macOS directory: `~/Library/Fonts`
- Linux directory: `~/.local/share/fonts`

## [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono)

JetBrains branding font.

Match my standard.

I use:

- `ss02`
- `cv04`
- `cv18`

## [Iosevka](https://github.com/be5invis/Iosevka)

I often choose SS08 variant because I also love PragmataPro too.

Match my standard.

Also:

- Has display font

Font is narrow, can display much more on small screen.

I have custom build [Iosevka Pacman](https://gist.github.com/haunt98/706f379a3a76c80d4b5dfc2e83e7d815) for my own use.

## [Recursive](https://github.com/arrowtype/recursive)

I often choose Casual variant.

Match my standard.

Also:

- Has display font

- [Designing Recursive](https://www.recursive.design/process/)

## [Sudo](https://github.com/jenskutilek/sudo-font)

Small fonts.

But:

- Has display font

I use:

- `cv06`
- `cv08`

## [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts)

For fancy terminal, only need `NerdFontsSymbolsOnly`.

## More fonts, but I don't use much now (some fonts I already try in the past)

- [Fira Code](https://github.com/tonsky/FiraCode): legend, best ligatures.
- [Input](https://input.djr.com/): legend.
- [Monoid](https://github.com/larsenwork/monoid): legend.
- [Fantasque Sans Mono](https://github.com/belluzj/fantasque-sans): handwriting vibe, beautiful italic.
- [agave](https://github.com/blobject/agave): small fonts, beautiiful curved look.
- [mononoki](https://github.com/madmalik/mononoki): share same vibe with agave.
- [Hermit](https://github.com/pcaro90/hermit): unique and sharp look.
- [APL-385](https://apl385.com/fonts/index.htm): wide look, feel nostalgic.
    - [APL386](https://github.com/abrudz/APL386): has ligatures.
- [M+](https://github.com/coz-m/MPLUS_FONTS): love japanese vibe, prefer M PLUS Code Latin 60 because it's wide.
- [Annotation Mono](https://github.com/qwerasd205/AnnotationMono): handwriting vibe, beautiful italic, love wide look.
    - Use ligatures: `liga, ss01, onum`
- [Ubuntu Sans Mono](https://github.com/canonical/Ubuntu-Sans-Mono-fonts) and
  [Ubuntu Sans](https://github.com/canonical/Ubuntu-Sans-fonts): nostalogic to me since first Linux distro I use is
  Ubuntu.
- [Cascadia Code](https://github.com/microsoft/cascadia-code): Microsoft branding font.
- [Monaspace](https://github.com/githubnext/monaspace): GitHub branding font.
    - [A LETTERMATIC CASE STUDY: MONASPACE](https://lettermatic.com/custom/monaspace-case-study)
    - Use ligatures: `calt, liga, ss01, ss02, ss03, ss06`
